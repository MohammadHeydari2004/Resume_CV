# 🌐 پورتفولیو شخصی - محمد حیدری

این مخزن (Repository) حاوی کد منبع وب‌سایت پورتفولیوی شخصی محمد حیدری، توسعه‌دهنده فرانت‌اند (Front-End Developer) است. این پروژه با هدف ارائه‌ی یک نمای حرفه‌ای، ساختاریافته و دسترس‌پذیر از سوابق، مهارت‌ها و راه‌های ارتباطی، در قالب یک معماری تک‌صفحه‌ای (Single-Page Architecture) پیاده‌سازی شده است.

## ✨ ویژگی‌های کلیدی

- **طراحی واکنش‌گرا (Responsive Design):** پیاده‌سازی شده با رویکرد اول-موبایل (Mobile-First) و بهره‌گیری از Media Queries گسترده جهت تضمین تجربه‌ی کاربری یکپارچه در تمامی ابعاد صفحه نمایش (موبایل، تبلت و دسکتاپ).
- **پشتیبانی بومی از حالت تاریک و روشن (Dark/Light Mode):** شامل تشخیص خودکار ترجیح رنگ سیستم‌عامل (`prefers-color-scheme`)، قابلیت تغییر دستی تم توسط کاربر و ذخیره‌سازی پایدار انتخاب در `localStorage`.
- **دسترسی‌پذیری پیشرفته (Web Accessibility):** رعایت استانداردهای WAI-ARIA با استفاده از ویژگی‌هایی نظیر `aria-label`، `aria-pressed`، `aria-current` و مدیریت دقیق حلقه‌ی فوکوس (`:focus-visible`) برای پشتیبانی از فناوری‌های کمکی.
- **پیمایش هوشمند (Scroll-Spy Navigation):** بهره‌گیری از `IntersectionObserver` در جاوااسکریپت برای تشخیص دقیق بخش فعال در حین پیمایش و به‌روزرسانی وضعیت ناوبری بدون تحمیل سربار عملکردی.
- **معماری CSS مبتنی بر توکن‌های طراحی (Design Tokens):** مدیریت متمرکز و مقیاس‌پذیر رنگ‌ها، تایپوگرافی، شعاع‌های گوشه و سایه‌ها با استفاده از متغیرهای بومی CSS (CSS Custom Properties).
- **بهینه‌سازی عملکرد (Performance Optimization):** استفاده از فونت وزیرمتن (Vazirmatn) با استراتژی `preconnect`، بارگذاری تنبل (Lazy Loading) برای منابع غیرضروری و بارگذاری پیش‌رونده (Eager Loading) برای محتوای حیاتی.

## 🛠️ پشته فناوری (Tech Stack)

- **HTML5:** نشانه‌گذاری معنایی (Semantic Markup) برای ساختاردهی استاندارد و بهینه‌سازی موتورهای جستجو (SEO).
- **CSS3:** استفاده پیشرفته از `CSS Grid`، `Flexbox`، `Custom Properties`، `Clamp()` برای تایپوگرافی سیال، و `Scroll Snap` برای کنترل رفتار پیمایش.
- **Vanilla JavaScript (ES6+):** توسعه‌ی ماژولار و بدون وابستگی (Dependency-Free) برای مدیریت وضعیت تم، محاسبه‌ی پویای ارتفاع هدر و ناوبری مبتنی بر پیمایش.

## 🚀 راهنمای اجرا و توسعه

برای اجرای این پروژه در محیط توسعه‌ی محلی (Local Development Environment)، مراحل زیر را دنبال نمایید:

1. **شبیه‌سازی مخزن (Clone Repository):**

   ```bash
   git clone https://github.com/MohammadHeydari2004/your-repo-name.git
   ```

2. **پیمایش به دایرکتوری پروژه:**

   ```bash
   cd your-repo-name
   ```

3. **اجرای پروژه:**
   فایل `index.html` را مستقیماً در مرورگر وب مدرن خود باز نمایید.
   > **تذکر:** با توجه به عدم وابستگی به ابزارهای بیلد (Build Tools) یا فریم‌ورک‌های سنگین، اجرای پروژه نیازمند هیچ‌گونه پیش‌نیاز خاصی (مانند Node.js یا Package Manager) نمی‌باشد. با این حال، برای تجربه‌ی بهتر توسعه، استفاده از افزونه‌ی "Live Server" در ویرایشگر VS Code توصیه می‌شود.
