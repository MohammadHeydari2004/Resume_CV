# 🌐 پورتفولیو شخصی - محمد حیدری

این یک پروژه وب‌سایت پورتفولیو شخصی (Resume/CV) است که برای معرفی "محمد حیدری"، توسعه‌دهنده فرانت‌اند ساخته شده است. این وب‌سایت به صورت تک‌صفحه‌ای (Single Page) طراحی شده و اطلاعات تماس، مهارت‌ها و معرفی کلی ایشان را به نمایش می‌گذارد.

## ✨ ویژگی‌ها

- **طراحی واکنش‌گرا (Responsive):** کاملاً سازگار با موبایل، تبلت و دسکتاپ (استفاده از Media Queries گسترده).
- **پشتیبانی از زبان فارسی (RTL):** جهت‌گیری راست‌چین استاندارد برای زبان فارسی.
- **استفاده از CSS Variables:** مدیریت متمرکز و تمیز رنگ‌ها، سایه‌ها، گرادیان‌ها و فونت‌ها.
- **فونت وزیرمتن:** استفاده از فونت زیبای وزیرمتن برای نمایش متون فارسی.
- **انیمیشن‌های CSS:** افکت‌های جذاب Hover و Transition برای المان‌های تعاملی.
- **چیدمان مدرن:** استفاده از Flexbox و CSS Grid برای ساختاردهی بخش‌های مختلف.

## 🛠️ تکنولوژی‌های استفاده شده

- **HTML5:** ساختار سمنتیک و استاندارد نشانه گذاری.
- **CSS3:** استایل‌دهی پیشرفته (Grid, Flexbox, Variables, Media Queries).

## 📁 ساختار پوشه‌ها

```text
.
├── css/
│   └── Style_1.css       # فایل اصلی استایل‌ها و تنظیمات واکنش‌گرا
├── Images/
│   └── profile.jpg       # تصویر پروفایل
├── js/
│   └── Script_1.js       # فایل جاوااسکریپت (در حال حاضر خالی و غیرفعال)
└── index.html            # ساختار اصلی وب‌سایت
```

## 📋 بخش‌های وب‌سایت

1. **هدر (Header):** منوی ناوبری چسبان (Sticky) با لینک‌های واسنجی نرم (Smooth Scroll).
2. **بخش معرفی (Hero):** معرفی نام، تخصص و یک بیوگرافی کوتاه همراه با عکس پروفایل.
3. **بخش مهارت‌ها (Skills):** نمایش مهارت‌ها (React, TypeScript, TailwindCss, HTML, CSS, JavaScript, WordPress, Git & Github) در قالب یک گرید منظم.
4. **بخش ارتباط (Footer):** راه‌های ارتباطی شامل ایمیل، تلفن، گیت‌هاب و لینکدین به همراه کپی‌رایت.

## 🚀 نحوه اجرا

برای اجرای این پروژه به صورت محلی، مراحل زیر را دنبال کنید:

1. ریپازیتوری را کلون کنید:
   ```bash
   git clone https://github.com/MohammadHeydari2004/your-repo-name.git
   ```
2. وارد پوشه پروژه شوید:
   ```bash
   cd your-repo-name
   ```
3. فایل `index.html` را در مرورگر خود باز کنید.
